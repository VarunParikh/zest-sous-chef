# Taxonomy format (seed for the 1,000-variant catalogue)
One line per base product, pipe-separated:
`base_id|category|name|term|unit|packs|ppu_inr|variants`
- `term`: the main lexicon ingredient (must exist in `ingredient_lexicon.csv`).
- `unit`: `g`, `ml` or `pc`. `packs`: pack sizes in that unit, separated by `/`.
- `ppu_inr`: mock price in rupees per 100 g, per 100 ml, or per piece (for `pc`). Prices are invented mock values, not market data.
- `variants`: items separated by `;`, each `Name~extra ingredients~price multiplier~flags`.
  - Extra ingredients are comma-separated lexicon terms added to `term`. The variant's ingredient list is `term` plus extras, so two variants with the same list must differ by a `=qualifier` (for example `=red`). This implements the owner's rule: a variant is unique by its ingredient list.
  - Flags: `g` gourmet, `o` organic, `-` none.
- A SKU is a variant times a pack size (generated). Stock, brand (generic names), and exact prices are generated by Claude Code on Day 1 from these rows with a fixed seed.
